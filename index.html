Part 1

Learn the ideas

Parts of a radical

5316
  • Coefficient (5): the number in front. It multiplies the radical.
  • Index (3): which root you take. No index written means 2, a square root.
  • Radical sign: the root symbol with its bar.
  • Radicand (16): the number or expression under the sign.

Entire radicals and mixed radicals

An entire radical has everything under the sign, like √{50}. A mixed radical has a coefficient outside, like 5√{2}. They can be equal: √{50} = 5√{2}. Pre-calc 11 expects you to move between the two forms in both directions.

Mixed → entire: raise the coefficient to the index, then move it inside

5√{2} = √{5² · 2} = √{25 · 2} = √{50}square the 5 because the index is 2
2∛{3} = ∛{2³ · 3} = ∛{24}cube the 2 because the index is 3

Entire → mixed: pull out the largest perfect square (or cube) factor

√{50} = √{25 · 2} = √{25} · √{2} = 5√{2}25 is a perfect square that divides 50

The rule that makes it all work

Product property of radicals

√{a} · √{b} = √{ab}   (a, b ≥ 0)

∛{a} · ∛{b} = ∛{ab}   (any real a, b)

It works for multiplication (and division). It does not work for addition: √{a + b} ≠ √{a} + √{b}.

Read left to right, it multiplies radicals. Read right to left, it splits a radical so you can simplify it. Keep these lists handy:

Simplifying a radical

A radical is in simplest form when the radicand has no perfect-square factor other than 1 (no perfect-cube factor for a cube root). There are two reliable methods.

Method 1: largest perfect square

√{180} = √{36 · 5}36 is the largest perfect square that divides 180
= √{36} · √{5} = 6√{5}product property, then take the root of 36

Method 2: prime factors in pairs

180 = 2 · 2 · 3 · 3 · 5break into primes
√{180} = 2 · 3 · √{5} = 6√{5}each pair leaves as one factor; the single 5 stays inside

For a cube root, look for groups of three: ∛{250} = ∛{5 · 5 · 5 · 2} = 5∛{2}.

Adding and subtracting

Like radicals have the same index and the same radicand. You combine them the way you combine like terms in algebra: add or subtract the coefficients and keep the radical unchanged. 3x + 5x = 8x, so 3√{2} + 5√{2} = 8√{2}.

Radicals that look unlike may become like once simplified, so always simplify first, then group, then combine.

Example

√{50} + √{32} − √{2}none of these look alike yet
= 5√{2} + 4√{2} − 1√{2}simplify each; √2 has a hidden coefficient of 1
= (5 + 4 − 1)√{2} = 8√{2}combine coefficients

Example with leftovers

2√{12} + √{27} − √{8}
= 2(2√{3}) + 3√{3} − 2√{2}simplify each radical
= 4√{3} + 3√{3} − 2√{2} = 7√{3} − 2√{2}√3 terms combine; the √2 term cannot

Multiplying

When the index matches, multiply coefficient by coefficient and radicand by radicand, then simplify. You do not need like radicals to multiply. One fact comes up constantly: √{a} · √{a} = a.

Monomial × monomial

(2√{6})(5√{15}) = 10√{90}2 · 5 = 10 and 6 · 15 = 90
= 10 · 3√{10} = 30√{10}√90 = √(9 · 10) = 3√10

Cube roots work the same way: ∛{9} · ∛{6} = ∛{54} = ∛{27 · 2} = 3∛{2}.

Distributive property

2√{3}(4 − √{6}) = 8√{3} − 2√{18}multiply 2√3 by each term
= 8√{3} − 6√{2}√18 = 3√2, so 2√18 = 6√2

Binomial × binomial (FOIL)

(√{6} + 2)(3√{6} − 1)
= 3·6 − √{6} + 6√{6} − 2First, Outer, Inner, Last
= 16 + 5√{6}whole numbers together, √6 terms together

Two special products

(2√{3} + 1)(2√{3} − 1) = (2√{3})² − 1² = 12 − 1 = 11conjugates: the middle terms cancel and no radical is left
(√{2} + 3)² = 2 + 2(3√{2}) + 9 = 11 + 6√{2}square of a binomial: a² + 2ab + b², never forget 2ab

Variables and restrictions

A square root (any even index) needs a radicand that is not negative, so you state a restriction on the variable. A cube root accepts any real number: ∛{−8} = −2.

  • √{x − 3} is defined only when x − 3 ≥ 0, so the restriction is x ≥ 3.
  • Pair up variable factors the same way as number factors: x³ = x² · x.
  • In general √{x²} = |x|. When the question gives x ≥ 0, you can write √{x²} = x.

Example, x ≥ 0

√{50x³} = √{25x² · 2x}25 and x² are perfect squares
= 5x√{2x}take them out; 2x stays inside

Part 3

Common pitfalls

Each card shows the mistake, the fix, and a calculator check you can use to catch it yourself.

Splitting a sum under the root

✗√{9 + 16} = 3 + 4 = 7
✓√{9 + 16} = √{25} = 5

The product property splits products, never sums. Work out what is under the sign first.

Check: 5 ≠ 7, so the shortcut fails.

Adding unlike radicals

✗√{2} + √{3} = √{5}
✓√{2} + √{3} is already as simple as it gets

Different radicands are like x and y. You can't combine x + y, and you can't combine these.

Check: 1.414 + 1.732 = 3.146, but √5 ≈ 2.236.

Adding the radicands too

✗3√{2} + 4√{2} = 7√{4}
✓3√{2} + 4√{2} = 7√{2}

Only the coefficients change. The radical is the "unit" being counted, just like 3x + 4x = 7x, not 7x².

Check: 7√2 ≈ 9.899, but 7√4 = 14.

Giving up before simplifying

✗√{8} + √{18} "can't be combined"
✓√{8} + √{18} = 2√{2} + 3√{2} = 5√{2}

Radicals that look different often share a radicand once simplified. Simplify every term before you decide.

Check: 2.828 + 4.243 = 7.071 and 5√2 ≈ 7.071.

Stopping halfway

✗√{72} = 2√{18} (final answer)
✓√{72} = √{36 · 2} = 6√{2}

18 still contains the perfect square 9. Use the largest perfect square, or look at your answer's radicand and check it for square factors.

Check: both equal 8.485, but only 6√2 is simplest form.

Moving a coefficient in without squaring it

✗3√{2} = √{6}
✓3√{2} = √{9 · 2} = √{18}

A number moving under a square root gets squared (cubed for a cube root), because 3 = √9.

Check: 3√2 ≈ 4.243, √6 ≈ 2.449, √18 ≈ 4.243.

Multiplying a coefficient into the radicand

✗2√{3} · 5 = 2√{15}
✓2√{3} · 5 = 10√{3}

Outside numbers multiply outside numbers. Inside numbers multiply inside numbers.

Check: 2√3 · 5 ≈ 17.32, 2√15 ≈ 7.746.

Squaring a root and getting the wrong number

✗√{3} · √{3} = 9 or √{3} · √{3} = √{3}
✓√{3} · √{3} = √{9} = 3

Squaring a square root undoes it. Likewise (2√{5})² = 4 · 5 = 20: square the coefficient and the radical.

Check: 1.732 × 1.732 ≈ 3.

Dropping the middle term when squaring

✗(√{5} + 2)² = 5 + 4 = 9
✓(√{5} + 2)² = 5 + 4√{5} + 4 = 9 + 4√{5}

(a + b)² = a² + 2ab + b². Writing it out as (√{5} + 2)(√{5} + 2) and using FOIL prevents this.

Check: 4.236² ≈ 17.944 and 9 + 4√5 ≈ 17.944.

Mixing different indices

✗√{2} · ∛{2} = √{4} or ∛{2} + √{2} = 2√{2}
✓ Leave as √{2} · ∛{2} and ∛{2} + √{2}

The product property and the like-radical rule both need the same index. A square root and a cube root are never like radicals.

Check: √2 · ∛2 ≈ 1.414 × 1.260 = 1.782, but √4 = 2.

Forgetting restrictions on variables

✗√{x²} = x for every x
✓√{x²} = |x|, which equals x only when x ≥ 0

For square roots, state the values that keep the radicand ≥ 0. Cube roots have no such restriction.

Check with x = −4: √((−4)²) = √16 = 4, not −4.

A · Simplifying Questions 1–5

  1. 1
    Simplify √{72}.
    Show solution
    √{72} = √{36 · 2}36 is the largest perfect square that divides 72
    = √{36} · √{2}product property
    = 6√{2}√36 = 6

    Answer: 6√{2}

    If you used 4 first you get 2√{18}, which still contains 9. Keep going: 2 · 3√{2} = 6√{2}. Same answer, one extra step.

  2. 2
    Simplify 3√{50}.
    Show solution
    √{50} = √{25 · 2} = 5√{2}simplify the radical first
    3√{50} = 3 · 5√{2} = 15√{2}multiply by the coefficient already outside

    Answer: 15√{2}

    The coefficient 3 waits outside the whole time. It multiplies whatever comes out of the radical.

  3. 3
    Simplify ∛{54}.
    Show solution
    ∛{54} = ∛{27 · 2}look for a perfect cube: 8, 27, 64 … and 27 divides 54
    = ∛{27} · ∛{2} = 3∛{2}∛27 = 3

    Answer: 3∛{2}

    A common slip is pulling out 9 because it is a perfect square. For a cube root, 9 does not help; you need groups of three equal factors (54 = 3 · 3 · 3 · 2).

  4. 4
    Write 4√{3} as an entire radical.
    Show solution
    4 = √{16}write the coefficient as a square root by squaring it
    4√{3} = √{16} · √{3} = √{48}product property

    Answer: √{48}

    Check: 4√3 ≈ 4 × 1.732 = 6.928 and √48 ≈ 6.928. Writing √12 (4 × 3) is the classic error.

  5. 5
    Simplify √{48x3}, where x ≥ 0.
    Show solution
    48x3 = 16 · 3 · x2 · xsplit numbers and variables into perfect squares and leftovers
    √{16x2} · √{3x}group the perfect squares together
    = 4x√{3x}√16 = 4 and √(x²) = x because x ≥ 0

    Answer: 4x√{3x}

    The restriction x ≥ 0 is what lets you write x instead of |x|.

B · Adding and subtracting Questions 6–11

  1. 6
    Simplify 5√{7} − 2√{7} + √{7}.
    Show solution
    5√{7} − 2√{7} + 1√{7}all like radicals; √7 has a coefficient of 1
    = (5 − 2 + 1)√{7} = 4√{7}combine coefficients only

    Answer: 4√{7}

    Forgetting the invisible 1 gives 3√7. Forgetting that radicands stay the same gives √21.

  2. 7
    Simplify √{12} + √{75}.
    Show solution
    √{12} = √{4 · 3} = 2√{3}simplify each term
    √{75} = √{25 · 3} = 5√{3}
    2√{3} + 5√{3} = 7√{3}now they are like radicals

    Answer: 7√{3}

    √87 is wrong: you can't add radicands.

  3. 8
    Simplify 2√{18} − √{50} + √{8}.
    Show solution
    2√{18} = 2 · 3√{2} = 6√{2}√18 = √(9 · 2)
    √{50} = 5√{2}√(25 · 2)
    √{8} = 2√{2}√(4 · 2)
    6√{2} − 5√{2} + 2√{2} = 3√{2}6 − 5 + 2 = 3

    Answer: 3√{2}

    Keep the minus sign attached to √50 throughout: it becomes −5√2.

  4. 9
    Simplify √{45} − √{20} + √{12}.
    Show solution
    √{45} = 3√{5}, √{20} = 2√{5}, √{12} = 2√{3}simplify each term
    3√{5} − 2√{5} + 2√{3}two like radicals and one that is different
    = √{5} + 2√{3}3 − 2 = 1, and 1√5 is written √5

    Answer: √{5} + 2√{3}

    This is the final answer. √5 and √3 are not like radicals, so the expression stops here.

  5. 10
    Simplify 2∛{16} + ∛{54} − ∛{2}.
    Show solution
    ∛{16} = ∛{8 · 2} = 2∛{2}8 is a perfect cube
    2∛{16} = 4∛{2}multiply by the coefficient 2
    ∛{54} = ∛{27 · 2} = 3∛{2}27 is a perfect cube
    4∛{2} + 3∛{2} − ∛{2} = 6∛{2}4 + 3 − 1 = 6

    Answer: 6∛{2}

  6. 11
    Simplify √{27x} + √{12x} − √{3x}, where x ≥ 0.
    Show solution
    √{27x} = √{9 · 3x} = 3√{3x}pull out 9
    √{12x} = √{4 · 3x} = 2√{3x}pull out 4
    3√{3x} + 2√{3x} − √{3x} = 4√{3x}all three share the radicand 3x

    Answer: 4√{3x}

    Variables inside the radicand must match too. √(3x) and √3 are not like radicals.

C · Multiplying and expanding Questions 12–18

  1. 12
    Simplify (3√{6})(2√{10}).
    Show solution
    = (3 · 2)√{6 · 10} = 6√{60}coefficients together, radicands together
    √{60} = √{4 · 15} = 2√{15}simplify the product
    6 · 2√{15} = 12√{15}

    Answer: 12√{15}

    Tip: factor before multiplying. 6 · 10 = (2 · 3)(2 · 5) shows the pair of 2s right away.

  2. 13
    Expand and simplify √{3}(√{6} − 2√{3}).
    Show solution
    = √{3} · √{6} − √{3} · 2√{3}distribute √3 to both terms
    = √{18} − 2 · 3√3 · √3 = 3
    = 3√{2} − 6√18 = √(9 · 2) = 3√2

    Answer: 3√{2} − 6

    These two terms are unlike (one has a radical, one doesn't), so you stop. Writing −6 + 3√2 is equally correct.

  3. 14
    Expand and simplify (2√{5} + 3)(√{5} − 4).
    Show solution
    F: 2√{5} · √{5} = 2 · 5 = 10first terms
    O: 2√{5} · (−4) = −8√{5}outer terms
    I: 3 · √{5} = 3√{5}inner terms
    L: 3 · (−4) = −12last terms
    10 − 12 + (−8 + 3)√{5} = −2 − 5√{5}collect whole numbers and √5 terms

    Answer: −2 − 5√{5}

    Paste these numbers into the binomial multiplier above to see the same four products in a grid.

  4. 15
    Expand and simplify (√{7} + √{2})(√{7} − √{2}).
    Show solution
    = 7 − √{14} + √{14} − 2FOIL
    = 5the middle terms cancel

    Answer: 5

    These are conjugates: same terms, opposite sign in the middle. They always follow (a + b)(a − b) = a² − b², so the radicals disappear. You'll use this to rationalize denominators.

  5. 16
    Expand and simplify (3√{2} − √{5})².
    Show solution
    (a − b)² = a² − 2ab + b²with a = 3√2 and b = √5
    a² = (3√{2})² = 9 · 2 = 18square the coefficient and the radical
    2ab = 2 · 3√{2} · √{5} = 6√{10}middle term
    b² = (√{5})² = 5
    18 − 6√{10} + 5 = 23 − 6√{10}combine 18 and 5

    Answer: 23 − 6√{10}

    Answering 23 (or 18 − 5 = 13) means the middle term was dropped. See the pitfall card above.

  6. 17
    Simplify ∛{4} · ∛{6}.
    Show solution
    = ∛{24}same index, so multiply the radicands
    = ∛{8 · 3} = 2∛{3}8 is a perfect cube

    Answer: 2∛{3}

    √24 would simplify to 2√6, but this is a cube root, so you need the cube factor 8, not the square factor 4.

  7. 18
    Expand and simplify (2√{x} + 3)(√{x} − 1), where x ≥ 0.
    Show solution
    F: 2√{x} · √{x} = 2x√x · √x = x
    O: −2√{x},   I: 3√{x},   L: −3
    2x + (−2 + 3)√{x} − 3 = 2x + √{x} − 3combine the √x terms

    Answer: 2x + √{x} − 3

D · Apply and explain Questions 19–22

  1. 19
    Which is greater, 3√{5} or 2√{11}? Do not use a calculator.
    Show solution
    3√{5} = √{9 · 5} = √{45}convert to an entire radical
    2√{11} = √{4 · 11} = √{44}same for the other
    √{45} > √{44}a bigger radicand gives a bigger square root

    Answer: 3√{5} is greater.

    Entire radicals make comparing easy. This is the main reason to know the mixed → entire direction.

  2. 20
    A rectangle has length 3√{8} + √{2} cm and width √{18} cm. Find its perimeter and area in simplest form.
    Show solution
    Length = 3 · 2√{2} + √{2} = 7√{2}√8 = 2√2
    Width = √{18} = 3√{2}√(9 · 2)
    P = 2(7√{2} + 3√{2}) = 2(10√{2}) = 20√{2}perimeter = 2(length + width)
    A = 7√{2} · 3√{2} = 21 · 2 = 42√2 · √2 = 2

    Answer: perimeter 20√{2} cm, area 42 cm²

  3. 21
    Jordan simplified (√{3} + 2)² and wrote 3 + 4 = 7. Explain the error and give the correct answer.
    Show solution
    (√{3} + 2)² = (√{3} + 2)(√{3} + 2)a square means the binomial times itself
    = 3 + 2√{3} + 2√{3} + 4FOIL gives two middle terms
    = 7 + 4√{3}combine

    Answer: 7 + 4√{3}. Jordan squared each term separately and lost the middle term 2ab = 4√3.

  4. 22
    Show that (1 + √{3})² − 2√{3} is a whole number.
    Show solution
    (1 + √{3})² = 1 + 2√{3} + 3 = 4 + 2√{3}square the binomial
    4 + 2√{3} − 2√{3} = 4the like radicals cancel

    Answer: the expression equals 4, a whole number.
